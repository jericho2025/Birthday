# Local birthday audio

No music or personal recordings are bundled. Add an authorized local audio file
here, then set `birthdayContent.cassette.audioSrc` to `/audio/your-file.mp3`.
Use a browser-supported format such as MP3, WAV, or Ogg. Set `songTitle`,
`artist`, `tapeLabel`, and `message` in the same config object.

This is a public repository. Add private or copyrighted audio only with explicit
direction and appropriate rights. Empty sources show an honest placeholder;
inspection keeps the journey completable without an audio file.
