# Birthday album photos

No personal images are included. Put approved local photos here, then edit
`src/config/birthdayBook.js`: each page has its own `imageSrc`, `imageAlt`,
optional `caption`, and optional `message`.

For example, a file named `01.jpg` here uses `/images/birthday-book/01.jpg`.
Photos use `object-fit: contain` to preserve the whole image. A missing or
empty source displays the page's numbered placeholder. This is a public
repository; add private media only with explicit authorization.
