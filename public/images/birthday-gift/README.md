Place the approved photo of the actual birthday watch here when ready.

Set `photo.src` in `src/config/birthdayGift.js` to its local path, for example
`/images/birthday-gift/watch.jpg`, and update `photo.alt`.

The empty default displays a labeled placeholder. Missing or failed photos also
fall back to that placeholder. The photograph only mounts after the box opens.

This repository is public. Add private media only with explicit approval.
